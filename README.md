# Nexus Gaming Store

A sleek, dark-themed frontend landing page for a digital gaming store. This project serves as a frontend development practice to implement modern gaming UI aesthetics using pure HTML and CSS.

## 🚀 Features
- **Gaming Aesthetic:** Dark UI layout with vibrant accents tailored for gamers.
- **Navigation Layout:** Clean header section for store navigation.
- **Product Showcase:** Section structured to display featured games, prices, and cards.
- **Content Segmentation:** Clearly separated blocks for store categories and promotions.

## 🛠️ Tech Stack
- **HTML5:** Core page structure.
- **CSS3:** Custom positioning, flex/grid layouts, and theme styling.
- **Webfonts:** Gaming-inspired typography and icons.

## ⚠️ Important Note
This project is **not responsive** and is optimized primarily for desktop screens. The main focus was capturing the visual style and structure of a modern gaming storefront.

## 📂 Project Structure
    ├── assets/       # Game banners, icons, and background images
    ├── css/          # Stylesheets for the dark theme
    ├── webfonts/     # Integrated fonts
    └── index.html    # Main store homepage

## 💻 How to Run
1. Clone the repository:
   git clone https://github.com/The-Real-Bedo/Nexus-Gaming-Store.git
2. Open `index.html` in your web browser to view the storefront.
